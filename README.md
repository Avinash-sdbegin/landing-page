# Landing Page

A modern, responsive landing page built with React and Vite. The project focuses on clean UI, fast performance, and mobile-friendly design.

## 🚀 Features

- Responsive Design
- Modern UI
- Fast Performance
- Component-Based Architecture
- Optimized for Desktop & Mobile

## 🛠️ Tech Stack

- React.js
- Vite
- JavaScript
- HTML5
- CSS3

## 📦 Installation

Clone the repository:

```bash
git clone https://github.com/Growthyari/landing-page.git
```

Navigate to the project directory:

```bash
cd landing-page
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

```
landing-page/
```

Open the application in your browser:

```
http://localhost:5173
```

## 🌐 Deployment

Build the project:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```

The project can be deployed on platforms such as:

- Hostinger
- Vercel
- Netlify
